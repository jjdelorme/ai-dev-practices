The “Ralph Loop” & /goal

Relentless Autonomous Iteration Against Deterministic Verification Gates
  • The “Ralph Wiggum Loop”: Coined by Geoffrey Huntley (while :; do cat PROMPT.md | agent ; done). A dead-simple outer loop that repeatedly re-runs the agent until objective reality—not the model's optimism—confirms the job is finished.
  • Why Single-Turn Agents Quit Early: Models suffer from premature completion bias. Left unchecked, an agent often stops after the first plausible edit or partial test pass instead of grinding through all edge cases.
  • /goal as a Native Harness Loop: Productizes the Ralph Loop inside the agent runtime. Intercepts normal turn termination, evaluates completion against explicit goal criteria, and forces continuation until 100% achieved.
  • Fueled by Verification Gates: Only works when paired with a strong harness. Compilers, test suites, and linters provide the deterministic feedback signal that guides each iteration toward convergence—even overnight.
