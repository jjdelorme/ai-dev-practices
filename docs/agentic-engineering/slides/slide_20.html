The Elephant-Goldfish Model (EGM)

“Design with an Elephant. Review with a Goldfish.”
  • The Elephant (Full Context): Deep-context architect that never forgets. Loads repo history, architecture, and boundaries to run structured brainstorming and draft living specs under docs/designs/.
  • The Goldfish Swarm (Zero Context): Stateless critics with fresh eyes. Isolated subagents read only the draft spec and live code—zero conversation bias—to stress-test assumptions before code is written.
  • Strict Design-Only Scope: Stops at the Design & Review boundary. Has no TDD construction or code-execution engine—agents are strictly forbidden from writing, modifying, or building production code (.h, .cc, .py, .go).
  • Structured Skill Workflow:
    • /egm-brainstorm & /egm-draft — Turn rough ideas into living design docs.
    • /egm-review & /egm-resolve — 5-stage zero-context adversarial review loop.
    • /egm-drift-report — Audits post-implementation code against the spec for divergence.
