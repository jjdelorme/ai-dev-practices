Specialized Roles & Clean Context Handoffs

Separating Planning, Coding, and Verification Without Chat Bloat
  • Specialized Role Separation: Strictly separates planning, coding, and verification. A Team Coordinator spawns dedicated Explorers, Builders, and Adversarial Critics.
  • Independent Final Auditor: Unbiased end-to-end verification. Once milestones complete, a fresh Independent Auditor steps in to validate every acceptance criterion.
  • Clean Context via File Handoffs: Zero chat-history bloat across agents. Subagents share concise Markdown reports on disk instead of dumping raw tool logs into a shared conversation.
  • Retire After Each Milestone: Every phase starts fresh. Subagents terminate once their milestone report is written, ensuring the next phase launches with a clean context window.
