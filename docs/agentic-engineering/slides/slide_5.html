THE SCAFFOLDING

Harness Engineering

Agent = Model + Harness: Wrapping Intelligence in Deterministic Guardrails
  • Scaffolding Dominates Success: A raw model is not an agent. Terminal Bench 2.0 proved that upgrading only the execution harness—with the exact same model—vaulted coding agents from outside the Top 30 into the Top 5.
  • Project Constitution & Tools: Codify context and capabilities. Ground the model with concise system rules (GEMINI.md / AGENTS.md), reusable skills, and scoped MCP tools inside isolated sandboxes.
  • Deterministic Verification Gates: Never trust probabilistic output alone. Enforce automated pre-commit hooks, linters, typecheckers, secret scanners, and test suites that block bad code mechanically.
  • Silent Success, Verbose Failure: Protect the context window. Keep passing checks silent to conserve tokens; emit structured, actionable stack traces only on failure to trigger autonomous self-repair.
  • Models Absorbing the Harness: Today's scaffolding is tomorrow's weights. Frontier labs report that multi-step loops, planning, and recovery are increasingly trained directly into model weights via RL—letting teams shed brittle code scaffolding while keeping thin, deterministic boundaries.
