THE KNOWLEDGE GRAPH

Open Knowledge Format (OKF)

A Git-Native "LLM Wiki" Built for Progressive Disclosure
  • An "LLM Wiki": Curated domain knowledge stored as plain Markdown in Git. Captures business rules, schemas, and playbooks in a human- and agent-readable wiki alongside your code.
  • Directory Hierarchy as a Graph: Organized into structured folders (index.md, concepts/, tables/). Directory trees and cross-references naturally form a lightweight knowledge graph without a database.
  • Built for Link Traversal: Models know how to follow links exceptionally well. Agents start at index.md and hop across standard Markdown links ([orders](../tables/orders.md)) on demand.
  • frontmatter & Progressive Disclosure: Every doc starts with YAML metadata (description, stale_after, verified). An agent can head -n 10 a file to inspect its frontmatter and decide if it needs to read the rest—protecting the context window.
