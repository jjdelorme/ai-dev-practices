Organizing Your Toolkit

Hierarchy of Context & Automation
  • GEMINI.md: The Project System Prompt. Clarifications, not textbooks. Remove ambiguity to save the context window.
  • Custom Commands: Saved Prompts. Static shortcuts for repetitive instructions and boilerplate generation.
  • Skills: Lazy-loaded, Dynamic Tools. Executes scripts (JS/Py/Bash). On-demand power, zero context bloat.
  • Sub-agents: Discrete Context Windows. Clean workspaces for complex tasks. Can execute Skills; still obeys GEMINI.md.
