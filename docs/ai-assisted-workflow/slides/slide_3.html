Prompting is Specification

Writing Effective Instructions for LLMs
  • Use Examples (Few-Shot): The #1 tip; often more effective than zero-shot. Provide concrete input-output pairs to anchor the model's behavior.
  • Clear, Explicit Instructions: Be precise; treat the LLM like an intern. Avoid ambiguity; define exact schemas, constraints, and success criteria.
  • Iterate and Experiment: Test, refine, and avoid superstitious additions. Don't add phrases based on folklore; measure prompt improvements systematically.
  • Leverage Models: Use LLMs to generate or improve prompts. Ask a stronger model to draft system instructions or build few-shot examples.
  • Provide Context Effectively: Place important data at top; use delimiters. Structure inputs with clear boundaries (e.g. XML tags or Markdown) to aid parser efficiency.
