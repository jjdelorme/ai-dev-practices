The Feynman Rule

Simple Explanation as the Ultimate Verification Gate
  • The Inbound Spec Litmus Test: If you can't explain it simply, you can't prompt it cleanly. Ambiguous or convoluted instructions cause model hallucination. Strip requirements down to first principles before delegating to AI.
  • The Outbound Ownership Gate: If you can't explain the generated code simply, you don't own it. Never merge or push code that hides behind syntactic complexity. Syntactic generation is not semantic comprehension.
  • The First-Principles Sparring Partner: Use AI to practice the Feynman Technique. Prompt the model to "explain this legacy module to me like I'm a junior engineer," then explain your design back to uncover blind spots.

"If you can't explain it simply, you don't understand it well enough."

— Richard Feynman • Physicist
