The Software Factory

Dan Shapiro's Five Levels: From Spicy Autocomplete to the Dark Factory
  • Level 1 — The Coding Intern: Discrete task execution. Offload isolated tasks (tests, docstrings); developer drives every core line at typing speed. (Level 0 = Spicy Autocomplete).
  • Level 2 — The Junior Developer: Multi-file pair programmer. Active collaborative flow on features; where 90% of "AI-native" developers currently plateau.
  • Level 3 — The Manager: Human-in-the-loop diff reviewer. AI writes the implementation while the developer shifts into a tech lead reviewing pull requests and diffs across tabs.
  • Level 4 — Spec-Driven (PM): Asynchronous execution from blueprints. Developer writes and debates specs, crafts skills, and steps away for hours while agent swarms build and test.
  • Level 5 — The Dark Software Factory: Lights-out autonomous production. A black box converting specs directly into verified software—where humans neither write nor review code.

"Level 2 feels like you are done. But you are not done."

— Dan Shapiro • The Five Levels
